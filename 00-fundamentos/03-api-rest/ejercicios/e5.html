E5 · Tres lenguajes, una API

Escribe tu API del E4 en los otros dos lenguajes hasta que las tres respondan exactamente lo mismo a las mismas peticiones.

Teoría
API 2 · La misma API en tres lenguajes
Aprendes
Que una API es su contrato, no su lenguaje: lo que no se ve desde fuera, no existe para el cliente.
Buena práctica
Que no se note el lenguaje: manda el contrato, no el framework.

Qué entregas

En fundamentos/api/e5/, tres carpetas y un fichero:

RutaQué lleva
go/La API completa del E4 en Go, con su Dockerfile.
python/La misma API en Python (FastAPI), con su Dockerfile.
node/La misma API en Node (Express), con su Dockerfile.
diferencias.mdAl menos tres cosas que un framework hacía distinto, qué respondía y cómo lo has igualado. Va en e5/, no dentro de una carpeta de lenguaje.

Una de las tres carpetas es tu E4 tal cual; las otras dos las escribes tú. El corrector construye las tres imágenes, comprueba que responden lo mismo a la misma serie de peticiones y pasa a cada una las pruebas del E4.

1Prepara el escenario

En la terminal, cambiando <tu-usuario> por tu usuario de GitHub:

Windows · PowerShell

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/00-fundamentos/03-api-rest/ejercicios/preparar.py e5
cd fundamentos/api/e5

macOS / Linux · Terminal

cd ~/hacking-etico/entregas-<tu-usuario>
python3 ../documentacion-hacking-etico/00-fundamentos/03-api-rest/ejercicios/preparar.py e5
cd fundamentos/api/e5

preparar.py copia tu E4 a la carpeta de su lenguaje (por ejemplo, e5/go/ si lo hiciste en Go) y deja el esqueleto de los otros dos en las suyas, con los mismos datos y las mismas pruebas.

2Escribe las otras dos

Programa en cada esqueleto lo mismo que ya tienes, ruta a ruta, con su Dockerfile. Cada carpeta se arranca y se prueba como en el E3, desde dentro de ella: por ejemplo, para la de Python, cd python, las órdenes de Python del paso 1 del E3 y, en otra pestaña desde esa misma carpeta, pruebas.py e4. Si te apoyas en la IA para traducir, pasa pruebas.py e4 a cada una antes de seguir.

3Arranca las tres a la vez

Para las APIs que tengas arrancadas en tu equipo (Ctrl+C). Con Docker Desktop en marcha, construye las tres imágenes y arráncalas, cada una en su puerto: Go en el 8001, Python en el 8002 y Node en el 8003. Desde fundamentos/api/e5/, en cualquier sistema:

docker build -t api-e5-go go
docker build -t api-e5-python python
docker build -t api-e5-node node
docker run -d --rm --name e5-go -p 8001:8000 api-e5-go
docker run -d --rm --name e5-python -p 8002:8000 api-e5-python
docker run -d --rm --name e5-node -p 8003:8000 api-e5-node

4Compáralas

Desde fundamentos/api/e5/, con los tres contenedores recién arrancados:

Windows · PowerShell

py go/pruebas.py e5 http://localhost:8001 http://localhost:8002 http://localhost:8003

macOS / Linux · Terminal

python3 go/pruebas.py e5 http://localhost:8001 http://localhost:8002 http://localhost:8003

Primero manda a las tres la misma serie de peticiones (leer, crear, cambiar, borrar, errores) y compara código, Content-Type, Location, Allow y cuerpo. Después pasa a cada una las pruebas del E4. Una diferencia sale así:

  ✗ DELETE /api/v1/incidencias: misma respuesta en las tres  (distinto: código · 405 | 405 | 404)

Ahí, Express ha respondido 404 porque de serie no conoce el 405. Está bien cuando la última línea dice 0 mal. Para volver a probar, para los tres contenedores y arráncalos otra vez; si has cambiado código, reconstruye antes su imagen con su docker build del paso 3:

docker stop e5-go e5-python e5-node
docker run -d --rm --name e5-go -p 8001:8000 api-e5-go
docker run -d --rm --name e5-python -p 8002:8000 api-e5-python
docker run -d --rm --name e5-node -p 8003:8000 api-e5-node

5Explica las diferencias

code diferencias.md

Al menos tres cosas que un lenguaje o su framework hacía distinto de los otros sin pedírselo (errores por defecto, cabeceras, tipos de los parámetros, valores null…), qué respondía y qué has cambiado para igualarlo. Son también las pistas con las que alguien de fuera adivinaría con qué está hecha una API.

Una diferencia por elemento de lista (o por apartado ##), cada una con las tres partes: qué petición, qué respondía cada lenguaje y qué has cambiado. Por ejemplo, la del paso 4:

1. **DELETE sobre la colección.** Go y FastAPI respondían 405 con Allow: GET, POST;
   Express respondía 404 en HTML porque no conoce el 405. He añadido en Express un
   app.all para la ruta que responde 405 con su Allow.
2. …
3. …

El corrector marca fallo si:

  • Alguna de las tres imágenes no construye o no escucha en el 8000.
  • Las tres no responden igual a la serie de peticiones de pruebas.py e5, o alguna no pasa las del E4.
  • diferencias.md no explica al menos tres diferencias y su arreglo.
