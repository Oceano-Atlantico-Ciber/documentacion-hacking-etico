02 · Docker

Imágenes, contenedores, datos, redes y compose, mirando siempre qué puerta abre cada opción. Cuatro temas y ocho ejercicios.

Temas

Docker 1 · Imágenes y contenedoresQué es un contenedor, Docker en Windows, el nombre de una imagen y el ciclo de vida. Docker 2 · Construir imágenesEl Dockerfile, ENTRYPOINT y CMD, capas, caché, .dockerignore y secretos en capas. Docker 3 · Datos y redesVolúmenes y montajes de carpeta, quién llega a un puerto publicado y redes con nombres. Docker 4 · Compose y seguridadLeer los compose del curso, up, run y exec, perfiles, variables y las puertas que abre un compose.

Ejercicios

Antes de empezar: Docker Desktop instalado (Presentación · Docker) y los pasos de instalación de Docker 1: docker login con tu cuenta de Docker Hub. Las órdenes de Windows son de PowerShell; las de macOS y Linux, del Terminal.

Ocho ejercicios en fundamentos/docker/ de tu repositorio de entregas, todos en main. Cada uno sigue el mismo camino:

preparar.py→hacer el ejercicio→commit→pruebas.py→push→etiqueta

Los que tienen ficheros de partida empiezan con preparar.py, que los escribe a partir de tu usuario de GitHub; en E4 además construye la imagen que vas a auditar. Ejecútalo desde tu repositorio, con Docker Desktop en marcha:

Windows · PowerShell

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/00-fundamentos/02-docker/ejercicios/preparar.py e1

macOS / Linux · Terminal

cd ~/hacking-etico/entregas-<tu-usuario>
python3 ../documentacion-hacking-etico/00-fundamentos/02-docker/ejercicios/preparar.py e1

Antes de etiquetar, compruébalo en tu equipo con pruebas.py. Pasa exactamente las mismas comprobaciones que el corrector, sobre lo que ya tienes en commits. Construye y levanta los contenedores como él, así que necesita Docker Desktop en marcha. Si algo falla, dice qué y por qué. Sin el número de ejercicio, los comprueba todos:

Windows · PowerShell

py ../documentacion-hacking-etico/00-fundamentos/02-docker/ejercicios/pruebas.py e1

macOS / Linux · Terminal

python3 ../documentacion-hacking-etico/00-fundamentos/02-docker/ejercicios/pruebas.py e1

Cada ejercicio se entrega con su etiqueta anotada, entrega-fundamentos-docker-eN, sobre main, igual que los de Git.

Puedes entregar cada ejercicio cuando lo tengas, y mover su etiqueta siempre que lo corrijas. El resultado del corrector aparece en GitHub como una comprobación: el icono ✓ o ✗ junto al último commit de main. Al pulsarlo verás Corrector docker, con una fila por ejercicio. Se actualiza cuando el docente lanza la corrección. El corrector construye tus imágenes y levanta tus contenedores de verdad.

Hazlos en orden: cada uno usa solo lo visto en su tema y en los anteriores, y E6 y E7 reutilizan lo de E2 y E5.
