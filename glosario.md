# Glosario de herramientas

| Herramienta | Para qué la usamos |
|---|---|
| Git | Guarda el historial de vuestro trabajo y es como entregáis cada semana. |
| Docker | Ejecuta programas en contenedores aislados sin instalarlos en vuestro equipo. |
| Docker Compose | Levanta varios contenedores a la vez a partir de un fichero; así arrancamos el laboratorio. |
| Floci | Emula una cuenta de AWS en local para practicar sin usar la nube real. |
| Trivy | Busca vulnerabilidades y malas configuraciones en ficheros, imágenes y código de infraestructura. |
| aws CLI | Habla con AWS (o con la cuenta emulada) desde la terminal. |
| Terraform | Describe infraestructura en ficheros de texto y la crea a partir de ellos. |
| Ollama | Ejecuta modelos de IA en local, sin enviar datos fuera. |
| nmap | Descubre qué equipos y servicios hay en una red. |
| tshark | Captura y analiza tráfico de red desde la terminal. |
| Suricata | Detecta ataques en el tráfico de red mediante reglas. |
| Python | Lenguaje con el que escribimos nuestros scripts. |
| iw | Consulta y configura tarjetas Wi-Fi en Linux. |
| SSH | Conecta de forma segura a otro equipo por la terminal. |
| GitHub Actions | Ejecuta comprobaciones automáticas en GitHub, por ejemplo al subir una entrega. |
