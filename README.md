# Documentación · Hacking ético

Repositorio público con todo el material de la asignatura de Hacking ético: las clases, los ficheros de cada sesión, las guías y los recursos que vayamos generando durante el curso.

## Estructura

- `semanas/sNN/`: la clase de la semana NN (`README.md`) y sus ficheros (`material/`).
- `guias/`: guías de uso de las herramientas (Git, Trivy, Suricata, tshark…).
- `recursos/`: referencias, plantillas y material de consulta.

## Repositorios de la asignatura

- [ejercicios-hacking-etico](https://github.com/Oceano-Atlantico-Ciber/ejercicios-hacking-etico): enunciados, ficheros de partida, normas de entrega y plantilla del repositorio de cada alumno.
- **documentacion-hacking-etico** (este): clases y material.
