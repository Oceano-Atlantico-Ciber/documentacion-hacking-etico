Hacking ético

Glosario

Las herramientas y siglas del curso, en una línea cada una y en orden alfabético.

Herramienta o términoQué es y para qué la usamos
aws CLIHabla con AWS, la nube de Amazon, desde la terminal. En el curso, con la copia simulada de Floci.
curlEnvía peticiones HTTP desde la terminal y muestra la respuesta. En PowerShell se escribe curl.exe, porque allí curl a secas es otra orden.
CVECommon Vulnerabilities and Exposures: el número que recibe cada fallo real de un producto concreto, por ejemplo CVE-2021-44228.
CWECommon Weakness Enumeration: catálogo de tipos de fallo de programación o de diseño, cada uno con su número, por ejemplo CWE-306.
DockerEjecuta programas en contenedores aislados, sin instalarlos en tu equipo.
Docker ComposeLevanta varios contenedores a la vez a partir de un fichero; así arrancamos los laboratorios.
F12Abre las herramientas de desarrollo del navegador: ves el código de la página y las peticiones que envía.
FlociSimula una cuenta de AWS en tu portátil para practicar sin usar la nube real.
GitGuarda el historial de tu trabajo y es como entregas.
git-filter-repoReescribe la historia de un repositorio, por ejemplo para borrar un secreto de todos los commits.
GitHub ActionsEjecuta tareas en los servidores de GitHub; el docente lo usa para lanzar el corrector.
GitHub CLI (gh)Inicia sesión en GitHub desde la terminal para clonar y subir sin contraseña.
iwConsulta y configura tarjetas Wi-Fi en Linux.
MITRE ATT&CKCatálogo de técnicas de ataque reales, cada una con su identificador (T1234).
nmapDescubre qué equipos y servicios hay en una red.
OllamaEjecuta un modelo de IA en tu equipo, sin enviar datos fuera.
PinggyPublica en Internet, con un enlace temporal, un servicio que se ejecuta en un equipo. El docente lo usa para compartir el juego de la presentación.
PowerShellLa terminal del curso en Windows. Con Invoke-RestMethod consultas además webs y API públicas, como NVD.
PythonEl lenguaje de nuestros scripts, como preparar.py y pruebas.py.
SSHConecta de forma segura con otro equipo desde la terminal.
SuricataDetecta ataques en el tráfico de red mediante reglas.
TerraformDescribe infraestructura en ficheros de texto y la crea a partir de ellos.
Tor BrowserNavegador de la red Tor. En el curso se explica cómo funciona, no se usa.
TrivyRevisa ficheros de infraestructura y dependencias y avisa de configuraciones peligrosas.
tsharkCaptura y analiza tráfico de red desde la terminal.
VS CodeEl editor del curso; Git lo abre cuando necesita que escribas un mensaje.
WSL 2Una máquina Linux ligera dentro de Windows. Docker Desktop la usa para ejecutar los contenedores.
