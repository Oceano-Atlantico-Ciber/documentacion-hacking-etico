Clase práctica. Ver que con curiosidad y práctica se hacen cosas reales sin saberlo todo, y salir con el equipo listo para el resto del curso.

1. Presentación

  • A qué se dedica el docente: trabajo como SRE (fiabilidad de sistemas en producción) y cómo se relaciona con la seguridad.
  • Experiencia práctica en hacking con proyectos propios, con demostración en vivo.
  • Nadie sabe de todo: lo que cuenta es saber buscar, probar, romper en un entorno controlado y aprender de ello.
  • Regla del curso: solo se ataca lo que está dentro del alcance autorizado.

2. Git y GitHub

  1. Instala Git: git-scm.com/downloads (en Linux, sudo apt install git).
  2. Configura tu identidad: 
    git config --global user.name "Tu Nombre"
git config --global user.email "tu@correo"
git config --global init.defaultBranch main
  3. Crea una cuenta en github.com si no la tienes y pásale tu usuario al docente.
  4. Comprueba: git --version

3. Docker

  • Windows: Docker Desktop con el motor WSL 2 (docs.docker.com/desktop).
  • macOS: Docker Desktop.
  • Linux: Docker Engine (docs.docker.com/engine/install) y tu usuario en el grupo docker.
docker run --rm hello-world
docker compose version

Con Docker funcionando podréis levantar Floci, la cuenta AWS emulada en la que trabajaremos todo el curso.

4. IA: local o en la nube

Elige una opción; las dos sirven para el curso.

Opción A · Local con Ollama

Los datos no salen de tu equipo. Necesita unos 8 GB de RAM libres para modelos pequeños.

  1. Instala Ollama: ollama.com/download.
  2. Descarga un modelo pequeño y pruébalo: 
    ollama pull llama3.2
ollama run llama3.2 "Explica en una frase qué es un escaneo de puertos"

Opción B · En la nube

El asistente que prefieras (por ejemplo Claude o ChatGPT) desde el navegador o su aplicación.

Regla para las dos: nunca pegues en una IA en la nube contraseñas, claves ni datos reales de terceros.

5. Minijuego «Hackea el ranking»

El docente despliega un juego en Floci, la nube emulada del curso (una web con su API y un ranking), y os da la dirección en la red del aula. El objetivo es subir al primer puesto del ranking… sin jugar limpio. Cada truco que funcione os da una flag que aparece en el marcador del proyector.

Alcance (léelo antes de empezar)

Autorizado: solo la dirección del juego que da el docente, solo durante esta clase. Nada de atacar la red del aula, los equipos de compañeros ni ningún otro servicio. Fuera de esto, lo mismo sería delito.

Con qué contáis

  • El navegador y sus herramientas de desarrollo (F12).
  • La terminal y curl.
  • Vuestra IA, para que os explique lo que vayáis encontrando.

Mientras jugáis, apuntad

  • Qué habéis probado y en qué orden: es el principio de las fases de un ataque.
  • Qué funcionó, por qué creéis que funcionó y cómo lo arreglaríais. Lo usaremos en la siguiente clase.

Comprobación final

  • ☐ git --version responde y tu identidad está configurada
  • ☐ Usuario de GitHub enviado al docente
  • ☐ docker run --rm hello-world funciona
  • ☐ IA local o en la nube respondiendo
  • ☐ Al menos una flag en el marcador y vuestras notas guardadas
