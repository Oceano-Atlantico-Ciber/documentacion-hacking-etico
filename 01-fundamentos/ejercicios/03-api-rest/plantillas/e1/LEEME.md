# E1 · HTTP a mano

La API del laboratorio escucha en http://localhost:8080 con tus incidencias.
Tu incidencia es la **{N}**: es la que tienes que leer en `peticion-get.txt`.

Si apagas el equipo, vuelve a arrancarla con:

    docker start api-e1

El enunciado completo está en la web del curso, en Ejercicios de API REST, E1.
