E2 · Diseña el contrato

Convierte lo que pide el equipo de sistemas en el contrato OpenAPI de la API de incidencias, antes de programar nada.

1Prepara el escenario

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/01-fundamentos/ejercicios/03-api-rest/preparar.py e2
cd fundamentos/api/e2

Deja requisitos.md, con lo que necesita el equipo de sistemas, y contrato.yaml con la ruta de salud y el principio del esquema Incidencia.

2Lee los requisitos como recursos

Antes de escribir, apunta en un papel: qué recursos hay (cosas con datos propios), cuál cuelga de cuál y, para cada requisito, qué método sobre qué ruta lo cumple. Los verbos de los requisitos («cerrar», «borrar las duplicadas») no van en las rutas: cerrar es cambiar el estado.

3Completa el contrato

code contrato.yaml
  • Una ruta por recurso y por elemento, bajo /api/v1/.
  • Los cinco métodos donde corresponda.
  • Para cada operación, todas sus respuestas: la buena (200, 201 o 204) y las de error (400, 404, 422…).
  • Los esquemas de los datos: Incidencia completo, lo que se envía al crear y lo que se envía al cambiar, y Comentario.

Pega el fichero en editor.swagger.io para ver que no tiene errores de formato y cómo queda como documentación.

4Compruébalo

Las pruebas del E2 leen tu contrato y aplican las reglas de diseño. Necesitan la librería PyYAML, una vez:

py -m pip install pyyaml
cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/01-fundamentos/ejercicios/03-api-rest/plantillas/pruebas.py e2 fundamentos/api/e2/contrato.yaml

El corrector marca fallo si:

  • contrato.yaml no es OpenAPI 3 válido.
  • Alguna ruta no empieza por /api/v1/, lleva un verbo o nombra una colección en singular.
  • No usa los cinco métodos, o un GET lleva cuerpo.
  • Un POST que crea no responde 201 o un DELETE no responde 204.
  • Una operación no declara ningún error 4xx, o una ruta con {id} no declara el 404.

A partir del E3 se programa el contrato de referencia del curso, el mismo para todos, para que el corrector pueda probar todas las APIs igual. Compáralo con el tuyo cuando lo recibas: si has seguido las reglas, se parecerán mucho.
