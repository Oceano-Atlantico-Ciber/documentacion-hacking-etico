E5 · Rebase

Un compañero ha subido un cambio a main mientras trabajabas en tu rama. Pon tu rama al día sin merges.

Teoría
Git 3 · Remotos y reescribir historia
Trabajas en
fundamentos/git/e5/
Etiqueta
entrega-fundamentos-git-e5 sobre git/e5-feature

1Prepara el escenario

Desde tu repositorio, en main y sin cambios pendientes:

py ../documentacion-hacking-etico/01-fundamentos/ejercicios/01-git/preparar.py e5

Crea git/e5-feature con dos commits y, después, añade un commit a main, como si lo hubiera subido un compañero. Míralo con git log --oneline --graph --all: las dos líneas se han separado.

2Rebasa la rama sobre main

git switch git/e5-feature
git rebase main

Si hubiera conflicto: resuélvelo, git add y git rebase --continue. Con git rebase --abort vuelves a como estaba.

3Comprueba antes de subir

git log --oneline --graph main git/e5-feature

Una sola línea: el commit del compañero y, encima, tus dos commits con SHA nuevos. Si ya habías subido la rama antes del rebase, el push se rechaza: súbela con git push --force-with-lease.

El corrector marca fallo si:

  • La rama no termina en sus dos commits, en el orden original.
  • Hay un merge en lugar de un rebase.
  • La rama no está encima del commit nuevo de main.

4Sube y etiqueta

git push origin main
git push -u origin git/e5-feature

En la portada de tu repositorio en GitHub, pulsa el ✓ o la ✗ junto al último commit de main y abre Details en Corrector git. Hay una fila por ejercicio, también para los que se trabajan en una rama, y se actualiza cuando el docente lanza la corrección: si has subido commits después, el último aún no tiene símbolo hasta la siguiente corrección. Cuando la fila de E5 salga sin fallos, etiqueta la punta de git/e5-feature:

git tag -a entrega-fundamentos-git-e5 git/e5-feature -m "E5 resuelto"
git push origin entrega-fundamentos-git-e5

Si el corrector marca fallos después de etiquetar, corrígelos, sube los cambios y mueve la etiqueta:

git tag -fa entrega-fundamentos-git-e5 git/e5-feature -m "E5 resuelto"
git push --force origin entrega-fundamentos-git-e5

Cuenta la etiqueta tal como esté al cerrar el plazo. Si la mueves después, la entrega queda fuera de plazo.
