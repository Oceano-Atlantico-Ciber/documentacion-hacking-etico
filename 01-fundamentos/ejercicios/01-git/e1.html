E1 · Identidad y commits atómicos

Configura tu identidad para que GitHub reconozca tus commits y versiona tres ficheros con un commit cada uno.

Teoría
Git 1 · Modelo y commits
Trabajas en
fundamentos/git/e1/
Etiqueta
entrega-fundamentos-git-e1 sobre main

1Comprueba tu identidad

git config user.name
git config user.email

El correo tiene que ser uno de los verificados en GitHub (Settings → Emails); el privado …@users.noreply.github.com también vale. Si no lo es, cámbialo antes de hacer commits, porque cada commit guarda el correo con el que se creó:

git config --global user.email "tu-correo-verificado"

2Prepara el escenario

Desde tu repositorio, en main y sin cambios pendientes:

py ../documentacion-hacking-etico/01-fundamentos/ejercicios/01-git/preparar.py e1

Deja tres ficheros sin versionar en fundamentos/git/e1/: objetivo.md, herramientas.md y notas.md. No cambies su contenido.

3Haz un commit por fichero

Cada commit lleva un solo fichero y un mensaje Conventional Commits: tipo(ámbito): descripción, con tipo feat, fix, docs, style, refactor, test o chore.

git add fundamentos/git/e1/objetivo.md
git commit -m "docs(e1): objetivo de la auditoría"

Repite con los otros dos ficheros, cada uno con su propio mensaje.

4Comprueba antes de subir

git log --oneline --stat -- fundamentos/git/e1

Tres commits y un fichero en cada uno.

El corrector marca fallo si:

  • No hay exactamente tres commits en e1/, o alguno cambia más de un fichero.
  • Algún mensaje no sigue Conventional Commits.
  • GitHub no asocia el correo del autor a tu cuenta.
  • Has cambiado el contenido de los ficheros.

5Sube y etiqueta

git push

En GitHub, cada uno de tus tres commits debe mostrar tu avatar y tu usuario. Si sale solo un nombre en gris, GitHub no ha asociado el correo a tu cuenta.

En la portada de tu repositorio en GitHub, pulsa el ✓ o la ✗ junto al último commit de main y abre Details en Corrector git. Hay una fila por ejercicio, y se actualiza cuando el docente lanza la corrección. Cuando la fila de E1 salga sin fallos, etiqueta:

git tag -a entrega-fundamentos-git-e1 -m "E1 resuelto"
git push origin entrega-fundamentos-git-e1

Cuenta la primera etiqueta que subas. Moverla o borrarla después no cambia la entrega.
