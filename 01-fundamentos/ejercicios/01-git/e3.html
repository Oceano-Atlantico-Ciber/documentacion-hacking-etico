E3 · Fusiones

Integra dos ramas en main de las dos formas posibles y aprende a distinguirlas en el grafo.

Teoría
Git 2 · Ramas y fusiones
Trabajas en
fundamentos/git/e3/
Etiqueta
entrega-fundamentos-git-e3 sobre main

1Prepara el escenario

Desde tu repositorio, en main y sin cambios pendientes:

py ../documentacion-hacking-etico/01-fundamentos/ejercicios/01-git/preparar.py e3

Crea las ramas git/e3-ff y git/e3-noff, con un commit cada una, y te deja en main. Míralas con git log --oneline --graph --all.

2Fusiona git/e3-ff con fast-forward

git merge --ff-only git/e3-ff

main avanza hasta el commit de la rama, sin crear ningún commit nuevo. Hazlo primero: después del siguiente paso ya no sería posible.

3Fusiona git/e3-noff con commit de merge

git merge --no-ff git/e3-noff

Se abre VS Code con el mensaje del merge: déjalo tal cual y cierra la pestaña para guardarlo. Si no se abre VS Code, revisa core.editor en 03 · Git y GitHub.

4Comprueba antes de subir

git log --oneline --graph -5

El commit de git/e3-ff está en la línea de main, sin merge, y encima hay un commit de merge con dos padres que trae git/e3-noff.

El corrector marca fallo si:

  • El commit de git/e3-ff entró mediante un merge.
  • git/e3-noff se integró sin commit de merge.
  • Falta o cambió el contenido de alguna de las dos ramas.

5Sube y etiqueta

git push

En la portada de tu repositorio en GitHub, pulsa el ✓ o la ✗ junto al último commit de main y abre Details en Corrector git. Hay una fila por ejercicio, y se actualiza cuando el docente lanza la corrección. Cuando la fila de E3 salga sin fallos, etiqueta:

git tag -a entrega-fundamentos-git-e3 -m "E3 resuelto"
git push origin entrega-fundamentos-git-e3

Cuenta la primera etiqueta que subas. Moverla o borrarla después no cambia la entrega.
