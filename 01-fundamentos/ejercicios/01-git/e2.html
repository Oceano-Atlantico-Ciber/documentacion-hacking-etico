E2 · .gitignore

Decide qué no debe entrar nunca en el repositorio y deja que git lo ignore por ti.

Teoría
Git 1 · Modelo y commits
Trabajas en
fundamentos/git/e2/
Etiqueta
entrega-fundamentos-git-e2 sobre main

1Prepara el escenario

Desde tu repositorio, en main y sin cambios pendientes:

python3 ../documentacion-hacking-etico/01-fundamentos/ejercicios/01-git/preparar.py e2

Deja en fundamentos/git/e2/ el programa app.py y lo que genera al ejecutarse: build/, depuracion.log y .env. Ahora git status te propone subirlo todo.

2Escribe el .gitignore

Crea fundamentos/git/e2/.gitignore. Las rutas que escribas en él son relativas a esa carpeta. Solo deben quedar para versionar app.py y el propio .gitignore.

El .gitignore de la raíz de tu repositorio ya ignora .env, pero no cuenta: el de e2/ tiene que ignorar los tres por sí mismo.

3Comprueba qué ignora

git status --short -uall fundamentos/git/e2
git check-ignore -v fundamentos/git/e2/build/salida.bin fundamentos/git/e2/depuracion.log fundamentos/git/e2/.env

La primera orden solo debe listar app.py y .gitignore. La segunda muestra, para cada fichero, la regla que lo ignora: las tres deben venir de fundamentos/git/e2/.gitignore.

4Haz el commit

git add fundamentos/git/e2
git commit -m "chore(e2): ignorar lo que genera la app"

No uses git add -f: saltaría el .gitignore.

5Comprueba antes de subir

git log --name-only --oneline -- fundamentos/git/e2

Solo deben aparecer app.py y .gitignore.

El corrector marca fallo si:

  • Alguno de los ficheros ignorados llegó a un commit, aunque lo borres después: sigue en la historia.
  • El .gitignore no ignora alguno de los tres.
  • Has cambiado app.py.

6Sube y etiqueta

git push

En la portada de tu repositorio en GitHub, pulsa el ✓ o la ✗ junto al último commit de main y abre Details en Corrector git. Hay una fila por ejercicio, y se actualiza cuando el docente lanza la corrección. Cuando la fila de E2 salga sin fallos, etiqueta:

git tag -a entrega-fundamentos-git-e2 -m "E2 resuelto"
git push origin entrega-fundamentos-git-e2

Cuenta la primera etiqueta que subas. Moverla o borrarla después no cambia la entrega.
