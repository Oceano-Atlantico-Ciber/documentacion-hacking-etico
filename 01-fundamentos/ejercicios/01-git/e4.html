E4 · Conflicto

Dos auditores han ampliado el mismo inventario. Une su trabajo y resuelve el conflicto según una regla.

Teoría
Git 2 · Ramas y fusiones
Trabajas en
fundamentos/git/e4/
Etiqueta
entrega-fundamentos-git-e4 sobre main

1Prepara el escenario

Desde tu repositorio, en main y sin cambios pendientes:

py ../documentacion-hacking-etico/01-fundamentos/ejercicios/01-git/preparar.py e4

Añade a main el inventario fundamentos/git/e4/puertos.txt y crea git/e4-a y git/e4-b: cada auditor ha encontrado un puerto más. Compara con git diff main git/e4-a.

2Fusiona la primera rama

git merge git/e4-a

Entra sin problemas.

3Fusiona la segunda

git merge git/e4-b
git status

Esta da conflicto: puertos.txt aparece como both modified y tiene marcadores <<<<<<<, ======= y >>>>>>>.

4Resuelve con la regla

Regla: el inventario final tiene todas las líneas de las dos ramas, una por puerto, ordenadas por número de puerto y sin marcadores de conflicto.

Edita el fichero y termina el merge:

git add fundamentos/git/e4/puertos.txt
git commit

No lo arregles con un commit aparte ni copiando el fichero: el corrector busca el merge que resolvió el conflicto.

5Comprueba antes de subir

git log --oneline --graph -4
git show HEAD:fundamentos/git/e4/puertos.txt

Un merge con dos padres y el inventario completo y ordenado.

El corrector marca fallo si:

  • No hay un merge que una git/e4-a y git/e4-b resolviendo un conflicto real.
  • puertos.txt conserva marcadores de conflicto.
  • puertos.txt no sigue la regla.

6Sube y etiqueta

git push

En la portada de tu repositorio en GitHub, pulsa el ✓ o la ✗ junto al último commit de main y abre Details en Corrector git. Hay una fila por ejercicio, y se actualiza cuando el docente lanza la corrección. Cuando la fila de E4 salga sin fallos, etiqueta:

git tag -a entrega-fundamentos-git-e4 -m "E4 resuelto"
git push origin entrega-fundamentos-git-e4

Si el corrector marca fallos después de etiquetar, corrígelos, sube los cambios y mueve la etiqueta a tu nuevo commit:

git tag -fa entrega-fundamentos-git-e4 -m "E4 resuelto"
git push --force origin entrega-fundamentos-git-e4

Cuenta la etiqueta tal como esté al cerrar el plazo. Si la mueves después, la entrega queda fuera de plazo.
