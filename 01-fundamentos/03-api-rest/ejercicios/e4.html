Hacking ético · Fundamentos · 03 · API REST

E4 · Escribir bien

Añade a tu API crear, sustituir, cambiar y borrar, con los códigos y las cabeceras que cualquier cliente HTTP espera.

Teoría
API 1 (métodos, idempotencia, códigos) y API 2
Aprendes
A responder cada escritura como manda HTTP, no como sale de serie.
Buena práctica
201 con Location, 204 sin cuerpo, 405 con Allow, idempotencia.
Trabajas en
fundamentos/api/e4/
Etiqueta
entrega-fundamentos-api-e4 sobre main
Plazo
El que anuncie el docente para la unidad

1Prepara el escenario

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/01-fundamentos/03-api-rest/ejercicios/preparar.py e4
cd fundamentos/api/e4

Copia tu E3 a e4/: sigues sobre tu propio código. Si usas Python o Node, vuelve a instalar las dependencias en la carpeta nueva.

2Programa las escrituras

PeticiónResponde
POST /api/v1/incidencias201, la incidencia creada y Location: /api/v1/incidencias/{id}. Si no llegan, estado es abierta y tecnico, null. Sin titulo o prioridad: 400 o 422.
PUT /api/v1/incidencias/{id}200 y la incidencia sustituida entera. Si falta alguno de los cuatro campos: 400 o 422.
PATCH /api/v1/incidencias/{id}200 con solo los campos enviados cambiados.
DELETE /api/v1/incidencias/{id}204 sin cuerpo. Después, esa incidencia da 404.
POST /api/v1/incidencias/{id}/comentarios201, el comentario con su incidencia y Location hacia él.
GET /api/v1/incidencias/{id}/comentarios/{comentario}200 con el comentario, o 404.
Un método que la ruta no tiene405 y Allow con los que sí: GET, POST en la colección; GET, PUT, PATCH, DELETE en un elemento.

Los ids nuevos nunca reutilizan uno existente ni uno borrado. Si a Allow se le añade HEAD, como hacen Go y FastAPI con las rutas GET, no pasa nada.

3Pruébalo

py pruebas.py e4 http://localhost:8000

Pasa también las del E3. Las pruebas crean y borran: reinicia la API antes de repetirlas. Cuando salgan todas en ✓, construye la imagen y pásalas contra el contenedor, como en el E3.

El corrector marca fallo si:

  • Alguna prueba de py pruebas.py e4 sale en ✗ contra la imagen.
  • Falla alguna de las que no ves: un id borrado reutilizado, un PUT que acepta la mitad de los campos, un DELETE con cuerpo.
