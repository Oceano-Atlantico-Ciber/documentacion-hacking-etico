E5 · Tres lenguajes, una API

Escribe tu API del E4 en los otros dos lenguajes hasta que las tres respondan exactamente lo mismo a las mismas peticiones.

Teoría
API 2 · La misma API en tres lenguajes
Aprendes
Que una API es su contrato, no su lenguaje: lo que no se ve desde fuera, no existe para el cliente.
Buena práctica
Que no se note el lenguaje: manda el contrato, no el framework.
Trabajas en
fundamentos/api/e5/go/, e5/python/ y e5/node/
Etiqueta
entrega-fundamentos-api-e5 sobre main
Plazo
El que anuncie el docente para la unidad

1Prepara el escenario

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/01-fundamentos/03-api-rest/ejercicios/preparar.py e5
cd fundamentos/api/e5

Copia tu E4 a la carpeta de su lenguaje y deja el esqueleto de los otros dos en las suyas, con los mismos datos y las mismas pruebas.

2Escribe las otras dos

Programa en cada esqueleto lo mismo que ya tienes, ruta a ruta, con su Dockerfile. Si te apoyas en la IA para traducir, pasa pruebas.py e4 a cada una antes de seguir.

3Arranca las tres a la vez

Cada una en su puerto, desde e5/:

docker build -t api-e5-go go
docker build -t api-e5-python python
docker build -t api-e5-node node
docker run -d --rm --name e5-go -p 8001:8000 api-e5-go
docker run -d --rm --name e5-python -p 8002:8000 api-e5-python
docker run -d --rm --name e5-node -p 8003:8000 api-e5-node

4Compáralas

py go/pruebas.py e5 http://localhost:8001 http://localhost:8002 http://localhost:8003

Primero manda a las tres la misma serie de peticiones (leer, crear, cambiar, borrar, errores) y compara código, Content-Type, Location, Allow y cuerpo. Después pasa a cada una las pruebas del E4. Una diferencia sale así:

  ✗ DELETE /api/v1/incidencias: misma respuesta en las tres  (distinto: código · 405 | 405 | 404)

Ahí, Express ha respondido 404 porque de serie no conoce el 405. Para volver a probar, para los tres contenedores con docker stop e5-go e5-python e5-node y arráncalos otra vez.

5Explica las diferencias

code diferencias.md

Al menos tres cosas que un lenguaje o su framework hacía distinto de los otros sin pedírselo (errores por defecto, cabeceras, tipos de los parámetros, valores null…), qué respondía y qué has cambiado para igualarlo. Son también las pistas con las que alguien de fuera adivinaría con qué está hecha una API.

El corrector marca fallo si:

  • Alguna de las tres imágenes no construye o no escucha en el 8000.
  • Las tres no responden igual a la serie de peticiones de py pruebas.py e5, o alguna no pasa las del E4.
  • diferencias.md no explica al menos tres diferencias y su arreglo.
