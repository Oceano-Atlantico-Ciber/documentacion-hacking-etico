Presentación · Semana 1

Primer commit

Deja preparadas las carpetas del curso y sube el primer commit, que demuestra que tu puesto de trabajo está listo. Necesitas haber hecho Git y GitHub.

Las carpetas del curso

Trabajarás con dos repositorios, uno al lado del otro dentro de una misma carpeta. Los ejercicios cuentan con esta estructura: desde tu repositorio llegan al material con ../documentacion-hacking-etico/.

hacking-etico/
├── documentacion-hacking-etico/   el material del curso (esta web); solo lo actualizas
└── entregas-<tu-usuario>/         tu repositorio privado: aquí trabajas y entregas

Pasos

En Git Bash, cambiando <tu-usuario> por tu usuario de GitHub:

  1. Crea la carpeta del curso y clona los dos repositorios: 
    mkdir ~/hacking-etico && cd ~/hacking-etico
git clone https://github.com/Oceano-Atlantico-Ciber/documentacion-hacking-etico.git
git clone https://github.com/Oceano-Atlantico-Ciber/entregas-<tu-usuario>.git
cd entregas-<tu-usuario>
  2. Copia el .gitignore de la plantilla a la raíz de tu repositorio. Evita que subas secretos, estados de Terraform o capturas de red: 
    cp ../documentacion-hacking-etico/plantilla-alumno/.gitignore .
  3. Crea fundamentos/puesto.txt con la versión de tus herramientas: 
    mkdir fundamentos
{ git --version; py --version; docker compose version; } > fundamentos/puesto.txt
code fundamentos/puesto.txt
    En VS Code, añade al final la respuesta de tu IA a «qué es un escaneo de puertos» y guarda.
  4. Commit y push: 
    git add .gitignore fundamentos/puesto.txt
git commit -m "chore: puesto de trabajo listo"
git push

Si ya hiciste el primer commit en la semana 1, haz solo lo que te falte: el clon del material al lado de tu repositorio y el .gitignore en la raíz.

Cada vez que empieces a trabajar

El material se actualiza durante el curso. Tráete la última versión antes de cada sesión:

git -C ~/hacking-etico/documentacion-hacking-etico pull

Comprobación

  • En ~/hacking-etico/ están las dos carpetas, una al lado de la otra
  • .gitignore y fundamentos/puesto.txt aparecen en tu repositorio en GitHub
  • El commit muestra tu avatar en GitHub: tu correo está asociado a tu cuenta
