Docker

Docker levanta los laboratorios del curso, empezando por Floci, la cuenta AWS emulada.

  1. Instala Docker Desktop desde PowerShell y ábrelo. Usa el motor WSL 2, que propone al arrancar la primera vez; si te pide reiniciar, reinicia: 
    winget install -e --id Docker.DockerDesktop
    Cuando diga que está en marcha, comprueba en Git Bash que responde: 
    docker run --rm hello-world
docker compose version
  2. Con Docker funcionando podréis levantar Floci, la cuenta AWS emulada en la que trabajaremos todo el curso. Si hay tiempo, dejadla descargando: docker pull floci/floci:latest.

Comprobación

  • docker run --rm hello-world funciona
