Git y GitHub

Git guarda la historia de tu trabajo; GitHub aloja el repositorio privado donde lo entregas.

  1. Instala Git (git-scm.com/downloads; en Linux, sudo apt install git) y configura tu identidad: 
    git config --global user.name "Tu Nombre"
git config --global user.email "un-correo-verificado-en-github"
git config --global init.defaultBranch main
  2. Cuenta en github.com si no la tienes. Pásale tu usuario al docente: con él se crea tu repositorio privado en la organización de la asignatura.

Los fundamentos de git (commits, ramas, conflictos, rebase y cómo deshacer) se trabajan en la semana 2, en los temas de git de Fundamentos.

Comprobación

  • git --version responde y tu identidad está configurada
  • Usuario de GitHub enviado al docente
