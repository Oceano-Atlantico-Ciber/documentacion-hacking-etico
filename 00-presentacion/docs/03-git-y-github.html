Git y GitHub

Deja tu portátil Windows listo para todo el curso: las herramientas, tu identidad en git y la sesión con GitHub. Se hace una vez y tarda unos quince minutos.

1 · Instala las herramientas

Abre PowerShell e instala con winget, el gestor de paquetes de Windows:

winget install -e --id Git.Git
winget install -e --id Python.Python.3.13
winget install -e --id GitHub.cli
winget install -e --id Microsoft.VisualStudioCode

Cierra PowerShell cuando acaben: los programas nuevos solo se ven en una terminal abierta después.

2 · Tu terminal: Git Bash

Desde aquí, todas las órdenes del curso se escriben en Git Bash, que se instala con Git (menú Inicio → Git Bash, o en VS Code: Terminal → New Terminal → Git Bash). Es la misma terminal que en Linux y en los servidores que auditaremos: cd, ls, cp, cat, rutas con /.

Python se ejecuta con py, no con python3: en Windows, python3 abre la Microsoft Store. Instala ya la herramienta que usaremos en Git 4:

py -m pip install git-filter-repo

3 · Configura git

git config --global user.name "Tu Nombre"
git config --global user.email "un-correo-verificado-en-github"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"
git config --global core.autocrlf true

El correo tiene que ser uno de los verificados en GitHub (Settings → Emails), o tus commits no se asociarán a tu cuenta. Con core.editor, cuando git necesite un mensaje (un merge, un rebase) abrirá una pestaña de VS Code: escribe, guarda y cierra la pestaña para continuar. core.autocrlf convierte los finales de línea de Windows al subir, para que el repositorio quede igual que en Linux.

4 · Conéctate a GitHub

  1. Cuenta en github.com si no la tienes. Pásale tu usuario al docente: con él se crea tu repositorio privado entregas-<tu-usuario> en la organización de la asignatura.
  2. Inicia sesión desde la terminal. Elige GitHub.com, HTTPS, autenticar git con tus credenciales y login with a web browser: 
    gh auth login
    Así git clone y git push de tus repositorios privados funcionan sin pedir contraseña. GitHub ya no acepta la contraseña de la cuenta desde git.

Los fundamentos de git (commits, ramas, conflictos, rebase y cómo deshacer) se trabajan en la semana 2, en los temas de git de Fundamentos. El siguiente paso práctico es el primer commit.

Comprobación

En Git Bash, cada orden responde sin error:

git --version
py --version
py -m git_filter_repo --version
gh auth status
git config --global --list
  • gh auth status dice que has iniciado sesión con tu usuario
  • git config --global --list muestra tu nombre, tu correo verificado y core.editor=code --wait
  • Usuario de GitHub enviado al docente
