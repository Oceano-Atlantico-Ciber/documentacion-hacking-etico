Hackea el ranking

Enunciado
Hackea el ranking: los cuatro objetivos y qué entregar
Ficheros
docker-compose.yml, server/server.py y web/index.html
Alcance
Solo la dirección del juego que proyecta el docente, solo durante la clase
Entrega
La ficha de los fallos, en el U3·E1 del RA1 (ra1/u3-e1/ranking.md)

Se juega con el navegador, las herramientas de desarrollo del navegador (F12), curl.exe y la IA.

Levantar el juego (docente)

El servidor tiene dos modos: trusted, que acepta la puntuación que manda el navegador, y validated, que lleva la cuenta de la partida en el servidor. Se juega con el primero y al final se despliega el segundo para comprobar que los mismos trucos ya no funcionan. Las órdenes se lanzan desde la carpeta 00-presentacion/hackea-el-ranking/.

Modo trusted:

Windows · PowerShell

$env:MODE = "trusted"
docker compose up -d --remove-orphans

macOS / Linux · Terminal

MODE=trusted docker compose up -d --remove-orphans

El juego queda en http://localhost:8080. Añade ?scoreboard a la dirección para la vista del proyector, que solo muestra el marcador.

Modo validated:

Windows · PowerShell

$env:MODE = "validated"
docker compose up -d --force-recreate --remove-orphans

macOS / Linux · Terminal

MODE=validated docker compose up -d --force-recreate --remove-orphans

Con el juego levantado, el docente abre el túnel de Pinggy. La orden es la misma en todos los sistemas e imprime la dirección https://….pinggy.link, que es la dirección del juego y el alcance de la práctica:

ssh -p 443 -R0:localhost:8080 free@a.pinggy.io

En el plan gratuito el túnel se cierra a los 60 minutos y, al reabrirlo, cambia la dirección: hay que volver a proyectarla. Levanta el juego antes de abrir el túnel; si no, la dirección responde con un error 502.

Para repetirlo en casa, levanta el juego en tu equipo con las órdenes del modo trusted. La dirección pasa a ser http://localhost:8080.
