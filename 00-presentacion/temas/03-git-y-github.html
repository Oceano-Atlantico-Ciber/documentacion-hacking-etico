Git y GitHub

Deja tu portátil listo para todo el curso: las herramientas, tu identidad en git y la sesión con GitHub. Se hace una vez y tarda unos quince minutos. Los pasos están para Windows, que es lo que usa casi toda la clase, y para macOS y Linux.

1 · Instala las herramientas

Git, Python, el GitHub CLI (gh), VS Code y git-filter-repo, la herramienta que usaremos en Git 4 para purgar secretos de la historia.

Windows: abre PowerShell desde el menú Inicio e instala con winget, el gestor de paquetes de Windows:

Windows · PowerShell

winget install -e --id Git.Git
winget install -e --id Python.Python.3.13
winget install -e --id GitHub.cli
winget install -e --id Microsoft.VisualStudioCode

Cierra PowerShell cuando acaben y abre otro: los programas nuevos solo se ven en una terminal abierta después. Instala entonces git-filter-repo con el Python que acabas de instalar:

Windows · PowerShell

py -m pip install git-filter-repo

macOS: con Homebrew; si no lo tienes, instálalo antes con la orden que da su portada. El cask de VS Code deja también la orden code en la terminal.

macOS · Terminal

brew install git python gh git-filter-repo
brew install --cask visual-studio-code

Linux: en Debian o Ubuntu, con apt:

Linux (Debian, Ubuntu) · Terminal

sudo apt update
sudo apt install git python3 python3-pip gh git-filter-repo
sudo snap install code --classic

Si tu distribución no trae gh o git-filter-repo en sus paquetes, sigue las instrucciones de cli.github.com para el primero e instala el segundo con pip3 install --user git-filter-repo. Sin snap, descarga el .deb de VS Code de code.visualstudio.com.

2 · Tu terminal

Windows: todas las órdenes del curso se escriben en PowerShell. La más cómoda es la de VS Code: Terminal → New Terminal, que en Windows abre PowerShell. Tres cosas que cambian respecto a lo que verás en tutoriales de Linux:

  • Python se ejecuta con py, no con python3: en Windows, python3 abre la Microsoft Store.
  • curl se escribe curl.exe: en PowerShell, curl a secas es otra orden (Invoke-WebRequest).
  • Una orden por línea: en PowerShell de Windows no existe && para encadenarlas. Los ficheros se crean y se editan con code <ruta>, no con echo … > fichero, que en PowerShell los escribe en una codificación que git no entiende.

macOS y Linux: la aplicación Terminal, o la de VS Code. Python se ejecuta con python3. Cuando una orden cambia según el sistema, los enunciados la dan dos veces, con su etiqueta encima: Windows · PowerShell y macOS / Linux · Terminal. Si solo hay un bloque, vale igual para todos.

3 · Configura git

Con tu nombre y tu correo, entre comillas:

git config --global user.name "Tu Nombre"
git config --global user.email "un-correo-verificado-en-github"
git config --global init.defaultBranch main
git config --global core.editor "code --wait"

El correo tiene que ser uno de los verificados en GitHub (Settings → Emails), o tus commits no se asociarán a tu cuenta. Con core.editor, cuando git necesite un mensaje (un merge, un rebase) abrirá una pestaña de VS Code: escribe, guarda y cierra la pestaña para continuar.

Los finales de línea cambian entre sistemas. core.autocrlf hace que el repositorio guarde siempre los de Linux:

Windows · PowerShell

git config --global core.autocrlf true

macOS / Linux · Terminal

git config --global core.autocrlf input

4 · Conéctate a GitHub

  1. Cuenta en github.com si no la tienes. Pásale tu usuario al docente: con él se crea tu repositorio privado entregas-<tu-usuario> en la organización de la asignatura.
  2. Inicia sesión desde la terminal. Elige GitHub.com, HTTPS, autenticar git con tus credenciales y login with a web browser: 
    gh auth login
    Así git clone y git push de tus repositorios privados funcionan sin pedir contraseña. GitHub ya no acepta la contraseña de la cuenta desde git.

Los fundamentos de git (commits, ramas, conflictos, rebase y cómo deshacer) se trabajan en la semana 2, en los temas de git de Fundamentos. El siguiente paso práctico es el primer commit.

Comprobación

Abre una terminal nueva. Cada orden responde sin error:

Windows · PowerShell

git --version
py --version
py -m git_filter_repo --version
gh auth status
git config --global --list

macOS / Linux · Terminal

git --version
python3 --version
git filter-repo --version
gh auth status
git config --global --list
  • gh auth status dice que has iniciado sesión con tu usuario
  • git config --global --list muestra tu nombre, tu correo verificado y core.editor=code --wait
  • Usuario de GitHub enviado al docente
