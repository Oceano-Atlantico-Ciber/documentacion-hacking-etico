Docker

Docker arranca programas aislados del resto de tu equipo sin instalarlos. Con él levantas los laboratorios del curso, empezando por Floci, la copia simulada de AWS.

Qué es

  • Una imagen es un paquete con un programa y todo lo que necesita para funcionar. Es el molde.
  • Un contenedor es ese programa en marcha, creado a partir de la imagen y aislado del resto del equipo.
  • Docker Desktop es la aplicación que crea y vigila los contenedores en Windows y macOS.

Los contenedores del curso son de Linux. En Windows, Docker Desktop los ejecuta dentro de WSL 2, una máquina Linux ligera que Windows trae de serie.

Instalación

  1. Instala Docker Desktop y ábrelo.

    Windows · PowerShell

    winget install -e --id Docker.DockerDesktop

    Al arrancar la primera vez te propone usar WSL 2: acéptalo. Si te pide reiniciar, reinicia.

    macOS / Linux

    En macOS, descarga Docker Desktop de docs.docker.com. En Linux, instala Docker Engine siguiendo la guía de tu distribución en docs.docker.com.

  2. Cuando Docker Desktop diga que está en marcha, comprueba que responde. Las órdenes son las mismas en PowerShell y en el Terminal: 
    docker run --rm hello-world
docker compose version
  3. Con Docker funcionando ya puedes levantar Floci, la copia simulada de AWS en la que trabajarás todo el curso. Si tienes tiempo, deja descargando su imagen: 
    docker pull floci/floci:latest

Comprobación

  • docker run --rm hello-world muestra su mensaje de saludo
