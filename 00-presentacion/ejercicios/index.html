01 · Hackea el ranking

Carpeta 00-presentacion/ejercicios/01-hackea-el-ranking/. Enunciado: Hackea el ranking. El juego lo despliega el docente en su equipo y se juega desde el navegador, F12, curl y la IA. Alcance: solo la dirección del juego, solo durante la clase.

El servidor tiene dos modos: trusted, que acepta la puntuación que manda el navegador, y validated, que lleva la partida en el servidor. Se juega con el primero y se termina desplegando el segundo para ver que los mismos trucos ya no funcionan.

MODE=trusted docker compose up -d --remove-orphans      # http://IP-DEL-DOCENTE:8080  (?scoreboard para el proyector)
MODE=validated docker compose up -d --force-recreate --remove-orphans

En Windows PowerShell: $env:MODE = "validated"; docker compose up -d --force-recreate --remove-orphans (y "trusted" para volver).

Publicarlo para la clase con Pinggy

El docente abre un túnel desde su equipo; la URL https://….pinggy.link que imprime es la dirección del juego y el alcance de la práctica. Se proyecta con ?scoreboard al final.

ssh -p 443 -R0:localhost:8080 free@a.pinggy.io

En el plan gratuito el túnel se cierra a los 60 minutos y al reabrirlo cambia la URL: hay que volver a proyectarla. El juego tiene que estar levantado antes de abrir el túnel o la URL responde 502.

Quien quiera repetirlo en casa puede clonar este repositorio y levantar el juego en su equipo: la dirección pasa a ser http://localhost:8080.
