Aplicaciones web

RA5 · Ataca y defiende aplicaciones web en un entorno de prueba: llega a datos o funciones que no deberías ver y corrige el fallo.

Contenidos básicos

Ataque y defensa en entorno de pruebas de aplicaciones web

  • Negación de credenciales en aplicaciones web: saltarse el inicio de sesión, o forzarlo probando muchas contraseñas, y cómo impedirlo.
  • Recolección de información.
  • Automatización de conexiones a servidores web (ejemplo: Selenium).
  • Análisis de tráfico a través de proxies de intercepción.
  • Búsqueda de vulnerabilidades habituales en aplicaciones web.
  • Herramientas para la explotación de vulnerabilidades web.

En Floci, la copia simulada de AWS

Una aplicación desplegada en Floci con tres servicios de AWS: Lambda (ejecuta tu código sin que gestiones un servidor), API Gateway (la puerta de entrada que recibe las peticiones HTTP) y DynamoDB (una base de datos). La auditas, la corriges y la vuelves a desplegar.

Entrega

Cada ejercicio se entrega con su propia etiqueta anotada, la que indica su enunciado, en la carpeta aplicaciones-web/ de tu repositorio. Las normas son las de la portada.
