## Deep Web no es Dark Web

La Deep Web es todo lo que no sale en un buscador, como el historial de mi cuenta del gimnasio.
La Dark Web solo se alcanza con programas especiales, como la versión .onion de un periódico.

2Rellena la tabla

Para cada red, elige un valor de cada lista de la plantilla y escríbelo tal cual. Contrasta el tema con la web oficial de cada proyecto: torproject.org, geti2p.net, hyphanet.org y el repositorio de ZeroNet en GitHub.

Al final, escribe dos frases que expliquen la diferencia entre Deep Web y Dark Web, cada una con un ejemplo tuyo.

El corrector marca fallo si:

  • Falta una red o un valor no es de su lista.
  • Hay valores que no corresponden a su red. Solo dice cuántos.
