U3·E3 · El registro de un incidente

Una ferretería encontró sus servidores cifrados un lunes. Tienes el registro de eventos del servidor del fin de semana: con PowerShell reconstruyes qué hizo el atacante, fase a fase, y pones a cada paso su técnica de MITRE ATT&CK.

1Prepara el ejercicio

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/01-hacking-etico/preparar.py u3-e3
cd ra1/u3-e3
code respuestas.json

registro.csv es distinto para cada alumno: otro atacante, otras cuentas, otras horas.

2Los eventos que importan

IdQué registra
5152 / 5156El cortafuegos bloquea o permite una conexión.
4625 / 4624Un inicio de sesión falla o funciona. Tipo 10 es escritorio remoto.
4720 / 4732Se crea una cuenta / se añade a un grupo.
7045Se instala un servicio.
1102Alguien borra el registro de auditoría.

3Investiga con PowerShell

$r = Import-Csv registro.csv
$r | Group-Object Id | Sort-Object Count -Descending
$r | Where-Object Id -eq 5152 | Group-Object Ip | Sort-Object Count -Descending
$r | Where-Object { $_.Id -eq 4625 -and $_.Ip -eq "<ip>" } | Measure-Object
$r | Where-Object { $_.Ip -eq "<ip>" -or $_.Id -in 4720,7045,1102 } | Format-Table

En el día normal también hay ruido: contraseñas mal escritas de los empleados y algún escaneo suelto de Internet. Busca la dirección que escanea muchos puertos seguidos y sigue sus pasos.

4Rellena las respuestas

CampoQué va
ip_atacanteLa dirección desde la que se escaneó y se entró.
intentos_fallidosCuántos 4625 hay desde esa dirección. Un número, sin comillas.
primer_accesoFecha y hora del 4624 del atacante, tal como aparece: aaaa-mm-dd hh:mm:ss.
cuenta_usada, cuenta_creadaLa cuenta con la que entró y la que creó.
servicio_instaladoEl programa de acceso remoto que instaló.
registro_borradoFecha y hora del 1102.
tecnicasPara cada evento, su técnica de ATT&CK como T1234 o T1234.001.

El corrector marca fallo si:

  • respuestas.json no es JSON válido.
  • Un dato no coincide con tu registro: la dirección, la cuenta, la hora, el número de intentos.
  • Una técnica no tiene el formato, o hay técnicas que no coinciden con la clave. De estas dice cuántas, no cuáles.
