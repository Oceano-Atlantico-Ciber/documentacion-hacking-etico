U2·E1 · El alcance de la clínica

Una clínica dental te contrata para un test de intrusión. Conviertes lo que cuenta en un alcance.json tan preciso que un programa puede decir, para cualquier dirección y cualquier hora, si la prueba está permitida.

1Prepara el ejercicio

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/01-hacking-etico/preparar.py u2-e1
cd ra1/u2-e1
code LEEME.md alcance.json

LEEME.md es tu encargo: las direcciones, las fechas y el horario son distintos para cada alumno.

2Escribe el alcance

CampoQué va
cliente, autorizaLa empresa, y nombre y cargo de quien firma.
tipocaja negra, caja gris o caja blanca, según lo que te dan.
dentroLista de direcciones y redes que se pueden probar, como "203.0.113.10" o "192.168.1.0/24".
fueraLista de direcciones que no se tocan aunque estén dentro de una red de dentro.
inicio, finPrimera y última noche de la prueba, como "2027-02-01".
horariodesde y hasta como "20:00". Si cruza la medianoche, la madrugada cuenta como parte de la noche anterior.
prohibidoValores de esta lista, tal cual: denegación de servicio, ingeniería social, modificar datos, borrar datos, escaneo, explotación.
emergencianombre y telefono del contacto de emergencia.

El correo en Microsoft 365 no tiene dirección en tu encargo: no lo pongas en dentro.

3Pregúntale a tu alcance

py en_alcance.py 203.0.113.10 "2027-02-03 23:30"
py en_alcance.py 203.0.113.10 "2027-02-03 12:00"

Cambia las direcciones y las fechas por las de tu encargo y prueba los casos difíciles: el datáfono, la madrugada de la última noche, la noche antes de empezar. El corrector hace lo mismo con nueve preguntas que no ves.

El corrector marca fallo si:

  • alcance.json no es JSON válido, o falta un campo o no tiene el formato de la tabla.
  • Alguna de sus preguntas (una dirección y un momento) sale distinta de lo que permite el encargo. Dice cuántas y pone un ejemplo.
  • El tipo, lo prohibido, quién autoriza o el contacto de emergencia no son los del encargo.

4Pruébalo, sube y etiqueta

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/01-hacking-etico/pruebas.py u2-e1
git add ra1/u2-e1
git commit -m "docs(ra1-u2-e1): alcance del test de intrusión de la clínica"
git push
git tag -a entrega-ra1-u2-e1 -m "U2·E1 resuelto"
git push origin entrega-ra1-u2-e1

pruebas.py ya hace las nueve preguntas; lo que no comprueba es el tipo y lo prohibido, que van con clave. Etiqueta cuando la fila de U2·E1 de Corrector ra1 salga sin fallos.
