U2·E2 · Un alcance con fallos

Otro auditor dejó firmado un alcance de doce cláusulas. Seis de ellas, si se trabaja así, meten en problemas al auditor, al cliente o a terceros, y cada una por un motivo distinto. Encuéntralas y di de qué tipo es cada fallo.

1Prepara el ejercicio

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/01-hacking-etico/preparar.py u2-e2
code ra1/u2-e2/fallos.md

Las cláusulas están en fallos.md, numeradas en un orden distinto para cada alumno.

2Clasifica cada cláusula

En la columna Fallo, «no» si la cláusula está bien, o el tipo de fallo tal cual:

TipoEl fallo está en…
autorizaciónquién autoriza o cómo.
objetivosqué se puede probar.
fechascuándo.
técnicascómo se prueba.
datosqué se hace con los datos que aparezcan.
tercerosalgo que no es del cliente.

El corrector marca fallo si:

  • Falta una cláusula, o un valor no es «no» ni un tipo de la lista.
  • No has marcado exactamente seis, o repites un tipo.
  • Hay cláusulas mal clasificadas. Dice cuántas, no cuáles.

3Pruébalo, sube y etiqueta

py ../documentacion-hacking-etico/01-hacking-etico/pruebas.py u2-e2
git add ra1/u2-e2
git commit -m "docs(ra1-u2-e2): fallos del alcance de Transportes Atlántico"
git push
git tag -a entrega-ra1-u2-e2 -m "U2·E2 resuelto"
git push origin entrega-ra1-u2-e2

Etiqueta cuando la fila de U2·E2 de Corrector ra1 salga sin fallos.
