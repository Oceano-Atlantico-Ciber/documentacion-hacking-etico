U1·E2 · Qué permite cada web

Muchas empresas publican cómo quieren que les avisen de un fallo y qué está permitido probar. Lees esas políticas con PowerShell, sin probar nada contra nadie.

1Prepara el ejercicio

cd ~/hacking-etico/entregas-<tu-usuario>
py ../documentacion-hacking-etico/01-hacking-etico/preparar.py u1-e2
code ra1/u1-e2/seguridad.md

2Lee tres security.txt

En PowerShell, descarga el fichero de una web. Pedir un fichero público que la propia web publica para esto no es ninguna prueba de seguridad:

(Invoke-WebRequest https://github.com/.well-known/security.txt).Content

Repite con otras webs hasta tener tres que lo tengan. Algunas que lo publican: github.com, google.com, cloudflare.com, gitlab.com, mozilla.org. Si una no lo tiene, PowerShell da un error 404: prueba otra.

Copia a la primera tabla de seguridad.md el dominio (solo el nombre, como github.com) y los campos Contact, Expires y Policy tal como aparecen. Si tiene varios Contact, copia uno. Si un campo no está, escribe «no tiene».

3Lee un programa de recompensas

Abre la política de uno de esos ficheros (el enlace de Policy) o la de otro programa de bug bounty. En la segunda tabla, resume con tus palabras qué permite probar y qué prohíbe. Busca sobre todo qué dicen de las denegaciones de servicio, de los datos de otros usuarios y de la ingeniería social.

Termina con dos o tres frases en «Qué he aprendido».

El corrector marca fallo si:

  • No hay tres dominios distintos, o alguno no tiene security.txt.
  • Contact o Policy no coinciden con el fichero de la web, o Expires no es una fecha. El corrector descarga los mismos ficheros: si la web lo cambia entre tanto, actualízalo.
  • Falta el programa de recompensas, su enlace https://, o qué permite y qué prohíbe.

4Pruébalo en tu equipo

py ../documentacion-hacking-etico/01-hacking-etico/pruebas.py u1-e2

5Sube y etiqueta

git add ra1/u1-e2
git commit -m "docs(ra1-u1-e2): políticas de seguridad de tres webs"
git push
git tag -a entrega-ra1-u1-e2 -m "U1·E2 resuelto"
git push origin entrega-ra1-u1-e2

Etiqueta cuando la fila de U1·E2 de Corrector ra1 salga sin fallos.
